# MODINFO.XML


## Location

```
7 Days To Die\
            └── Mods\
                └── My New  Mod\ 
                    └── ModInfo.xml 
```

## Example

```
<?xml version="1.0" encoding="UTF-8"?>
<xml>
    <Name value="scan_disableworldlights"/>
    <DisplayName value="DisableWorldLights"/>
    <Version value="1.0.0"/>
    <Description value="DisableWorldLights mod."/>
    <Author value="scaN"/>
    <Website value="https://github.com/scaN-7dtd"/>
</xml>
```

## Identifier

This line `<Name value="scan_disableworldlights"/>` is your mod identifier.
